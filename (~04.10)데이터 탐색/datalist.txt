======예시 작성 양식=======
전체적으로 통용되는 얘기같습니다. 상권의 흐름을 잡으려면 시간 순서대로 진행되는걸 이용해도 좋을꺼같아요.
2021년에는 이랬는데, 2022,2023을 거쳐 2024년에는 어떠케 변했다 이런식으로. 
======================
데이터: 서울시 상권분석서비스(점포-행정동)
링크: https://data.seoul.go.kr/dataList/OA-22172/S/1/datasetView.do
분야: (교통, 문화, 인구, 환경 등)
사용 Feature:
1. 행정동_코드_명: (설명 필요할 경우 간단히 설명)
2. 점포_수
3. 서비스_업종_코드_명
    => 유사업종점포수 같은거 이용해도 좋을꺼같아요.
비고: 데이터 총 몇건, 몇년도 데이터 등 특이사항 있을 시 작성 
      2024년데이터까지 밖에 없습니다..
    => 이건 통계적인 특성이 강함. (그 동네의 개폐업률, 유사업종점포수 등) ==> 동네전체의 데이터를 읽어오기 좋음




======================
API : Kakao developers REST API
링크: https://developers.kakao.com/docs/latest/ko/local/dev-guide#search-by-keyword
사용 Parameter:
query: 업종명 (예: "카페", "치킨")
category_group_code: 
x: 점주 가게 경도
y: 점주 가게 위도
radius: 500
size: 15
sort: distance
    => "점주의 정확한 가게위치 주변 반경 500m 이내의 유사업종점포수" 추출가능
======================
데이터: 서울시 지하철 호선별 역별 시간대별 승하차 인원 정보
링크: https://data.seoul.go.kr/dataList/OA-12252/S/1/datasetView.do
분야: 교통
사용 Feature:
1. 호선명
2. 지하철역
3. 시간단위 승차인원
4. 시간단위 하차인원
비고: 월별로 제공되는 데이터, 현재 2026년 3월 한달을 기준으로 함
======================
데이터: 서울특별시 명절 이벤트 운영 전통시장
링크: https://data.seoul.go.kr/dataList/OA-22876/S/1/datasetView.do
분야: 문화/관광
사용 Feature:
1. 자치구
2. 시장명: 수유시장
3. 행사일: 26.2.11(수) 당일 또는 26.2.2.(월)~2.6.(금) 여러 날짜로 구성
4. 행사내용(요약)
======================
데이터: 서울시 전통시장 현황
링크: https://data.seoul.go.kr/dataList/OA-1176/S/1/datasetView.do
분야: 산업/경제
사용 Feature:
1. 자치구
2. 시장명
3. 형태: 건물형, 골목형, 지하도상가
4. 점포 수: integer
비고: 25.7.31 기준이 최신 
======================
데이터: 서울시 상권분석서비스(길단위인구-상권)
링크: https://data.seoul.go.kr/dataList/OA-15568/S/1/datasetView.do
분야: 인구
사용 Feature:
1. 상권_구분_코드_명
2. 총_유동인구_수
3. 연령대별 유동인구 (10대 ~ 60대 이상)
4. 시간대별 유동인구 (0~6시, 6~11시, 11~14시, 14~17시, 17~21시, 21~24시)
5. 요일별 유동인구 (월~일)
비고: 상권별 유동인구의 특성을 파악하기 좋음 (각 연령대의 시간대별 유동 인구수 파악 용이)
======================
데이터: 서울시 상권분석서비스(추정매출-상권) => 하이라이트
링크: https://data.seoul.go.kr/dataList/OA-15572/S/1/datasetView.do
분야: 산업/경제
사용 Feature:
1. 상권_코드_명
2. 서비스_업종_코드_명
3. 당월_매출_금액 / 당월_매출_건수
4. 주중/주말/요일별/시간대별 매출 금액 및 건수
5. 성별/연령대별 매출 금액 및 건수
비고: 
- 업종별 매출 규모와 건수를 통해 상권별 특색 정의하기 용이
- 단순 점포 수보다 실질적인 결제 데이터 기반의 상권 성격 파악 가능
======================
데이터: 주요 상권별 상가영업 현황 정보
링크: https://www.data.go.kr/data/100396938/linkedData.do
분야: 상권/상가
사용 Feature:
1. 상권명 및 상권번호
2. 시도명 및 시군구명
3. 상권 내 상가건물 비율:
   - (영업 중) (영업 정지) (폐업) (휴업) (시각화용)
비고: 
- 상권의 활성도(영업/폐업 비율)를 시각화하고 분석하는 데 최적화된 데이터
======================
데이터: 서울시 영세자영업 지역별 매출액 통계
링크: https://data.seoul.go.kr/dataList/DT201015017/S/2/datasetView.do
분야: 산업/경제
사용 Feature:
1. 자치구별&서울시 전체 외식업, 서비스업, 소매업 매출액
비고: 
- 통계데이터임, 2018년부터 2023년까지의 년 단위 데이터
- 영세자영업의 지역별 매출액을 볼 수 있음!
