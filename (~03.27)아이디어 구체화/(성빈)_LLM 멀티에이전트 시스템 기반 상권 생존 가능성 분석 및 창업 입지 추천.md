# LLM 멀티에이전트 시스템 기반 상권 분석 및 창업 입지 의사결정 지원

## 1. 제안 배경

서울에서 예비창업자가 가장 어려워하는 것은 단순히 "유동인구가 많은 곳을 찾는 것"만이 아님. 실제로는 **매출 규모**, **상권의 생존력**, **배후 수요**, **생활인구 흐름**, **경쟁 강도**, **지역의 변화 추세**가 복합적으로 작용함. 그러나 일반 사용자가 이 정보를 여러 공공데이터에서 직접 찾아 해석하기는 어려우며, 같은 지역이라도 업종에 따라 유리함과 불리함이 다르게 나타남.

본 시스템은 서울시 공공데이터를 기반으로 상권의 현재 상태와 변화 방향을 종합적으로 해석하고, 사용자가 고려 중인 업종과 입지에 대해 **진입 적합성**, **주의 요인**, **대안 입지 비교 정보**를 설명형 리포트로 제공하여 창업 의사결정을 지원하는 것을 목표로 함.

---

## 2. 서비스 목표

본 시스템은 사용자가 특정 점포 후보지, 행정동, 혹은 관심 상권을 선택했을 때 창업 판단에 필요한 핵심 정보를 구조화하여 제공하는 것을 목표로 함.

- 이 입지는 현재 창업 진입을 검토할 만한 조건을 갖추고 있는가
- 이 상권은 유입형 상권인지, 고정 수요형 상권인지
- 매출 규모 대비 신규 진입 시 주의가 필요한 구간인가
- 선택한 업종과 상권 특성이 얼마나 부합하는가
- 비슷한 조건의 대안 입지와 비교했을 때 상대적 장단점은 무엇인가

즉, 단순 추천 시스템이 아니라 **창업 전 사전 진단 및 의사결정 지원 시스템**으로 기능함이 핵심임.

## 3. 활용 공공데이터

### 3.1 서울시 상권분석서비스(추정매출-상권)
- **출처:** [서울 열린데이터광장 (OA-15572)](https://data.seoul.go.kr/dataList/OA-15572/S/1/datasetView.do)
- **데이터 목적:** 상권 단위 매출 규모 및 매출 잠재력 분석
- **활용 방향:** 특정 상권의 업종별 매출 규모, 계절성, 규모 차이를 반영하여 "겉보기 유동"과 "실질 매출력"을 분리한 해석 수행

### 3.2 서울시 상권분석서비스(상권변화지표-상권)
- **출처:** [서울 열린데이터광장 (OA-15576)](https://data.seoul.go.kr/dataList/datasetView.do?currentPageNo=1&infId=OA-15576&serviceKind=1&srvType=A)
- **데이터 목적:** 상권의 구조적 변화 방향 및 진입 안정성 분석
- **활용 방향:** 신규 진입 주의 상권인지, 기존 업체가 강한 상권인지, 신규 업체에 유리한 상권인지 구분

### 3.3 서울시 상권분석서비스(상주인구-상권)
- **출처:** [서울 열린데이터광장 (OA-15584)](https://data.seoul.go.kr/dataList/OA-15584/S/1/datasetView.do)
- **데이터 목적:** 상권 내 고정 수요 기반 파악
- **데이터 설명:** 서울시 상권 영역 내 상주인구 정보를 제공하며, 1년 중 4분기에 한 번 데이터를 업데이트하여 다음 해 1, 2, 3분기의 값이 동일하게 유지됨
- **활용 방향:** 출퇴근형 상권인지, 주거 기반 상권인지, 일상 소비형 업종에 적합한지 분석

### 3.4 행정동 단위 서울 생활인구(내국인)
- **출처:** [서울 열린데이터광장 (OA-14991)](https://data.seoul.go.kr/dataList/datasetView.do?infId=OA-14991&serviceKind=1&srvType=S)
- **데이터 목적:** 실제 시간대별 체류 인구 흐름 반영
- **활용 방향:** 같은 상권이라도 낮·밤·주중·주말의 인구 움직임을 비교하여 업종 적합성 평가

### 3.5 서울시 상권분석서비스(영역-상권)

- **데이터 목적:** 상권 영역 매핑 및 공간 시각화
- **활용 방향:** 상권 단위 분석 결과를 지도 기반 UI에 시각화하고, 후보 입지가 어느 상권에 속하는지 식별

### 3.6 서울시 상권분석서비스(추정매출-행정동)
- **출처:** [서울 열린데이터광장 (OA-22175)](https://data.seoul.go.kr/dataList/OA-22175/A/1/datasetView.do)
- **데이터 목적:** 행정동 단위 매출 추세 비교
- **활용 방향:** 후보지가 상권 경계에 걸쳐 있을 때 보조 판단 지표로 활용

## 4. 시스템 구성 개념

본 시스템은 여러 에이전트가 동일 입지를 각기 다른 관점에서 해석한 뒤, 이를 종합하여 최종 진단 리포트와 주의 사유를 생성하는 구조를 가짐.

### 4.1 Demand Agent
이 에이전트는 상권 내 상주인구와 생활인구를 바탕으로 수요 특성을 해석함.

예를 들어 다음과 같은 특성에 대한 분석 수행.

- 주중 점심 유입은 높으나 야간 체류가 낮은 상권
- 주거지 기반의 저녁 소비형 상권
- 주말 집중형 상권

이를 통해 업종이 테이크아웃형인지, 식사형인지, 체류형인지에 따라 입지 적합성을 다르게 평가함.

### 4.2 Revenue Agent
이 에이전트는 추정매출 데이터를 이용해 해당 상권의 매출 기대 수준을 산출함.

단순 평균이 아니라 업종군과 지역 단위를 반영해 **상대적으로 기대 가능한 매출 수준**을 계산하고, 후보 입지 간 차이를 수치화함. 즉, 사람이 흔히 "여기 사람 많으니까 장사 잘되겠지"라고 착각하는 부분에 대한 보정 역할 수행.

### 4.3 Stability Agent
이 에이전트는 상권변화지표를 기반으로 해당 지역이 안정적 성장 상권인지, 신규 진입에 조심해야 하는 상권인지 해석함.

이때 상권이 일시적으로 좋아 보이더라도 구조적으로는 폐업 위험이 높은 지역인지 확인하는 역할 수행. 쉽게 말해 **지금 반짝 좋아 보이는 상권**과 **지속 가능한 상권**을 구분하는 축으로 기능함.

### 4.4 Matching Agent
이 에이전트는 사용자가 입력한 업종, 예산, 희망 지역, 운영 시간대 등을 받아 상권 특성과의 궁합을 평가함.

예를 들어 같은 입지라도 카페에는 맞지만 저녁형 주점에는 약할 수 있고, 배달형 소규모 음식점에는 유리하지만 체류형 매장에는 불리할 수 있음. 즉, 입지 자체의 절대평가가 아니라 **업종-입지 적합도**를 계산함.

### 4.5 Master Agent
각 분석 결과를 통합해 최종적으로 다음과 같은 진단 결과를 제공함.

- 진입 검토 가능
- 주의 필요
- 보수적 접근 권장

그리고 그 이유를 자연어로 설명함. 결과는 단순 점수 제시보다 **어떤 요인이 진입 판단에 영향을 주는지**, **어떤 부분에서 주의가 필요한지**, **대안 입지와 비교했을 때 차이가 무엇인지**를 함께 제공하는 형태가 적절함.

## 5. 핵심 평가 로직 예시

본 시스템은 다음과 같은 관점으로 상권을 평가함.

- **수요 충분성:** 생활인구와 상주인구가 업종 운영 시간대와 맞는가
- **매출 기대치:** 동일 유형 상권 대비 추정매출이 충분한가
- **상권 안정성:** 상권변화지표상 신규 진입 리스크가 과도하지 않은가
- **입지 적합성:** 사용자의 업종과 상권 성격이 맞는가
- **대안 비교성:** 인근 후보지보다 상대적으로 우위가 있는가

즉, "좋은 상권인가?"를 단정하는 것이 아니라, **"이 업종으로 이 입지를 검토할 때 어떤 점을 참고해야 하는가?"**를 해석하는 구조임.

## 6. 사용자 경험 시나리오

1. 사용자가 지도에서 창업 후보 지역을 선택하거나, 관심 있는 행정동 또는 상권명을 검색함
2. 업종, 창업 예산, 운영 희망 시간대, 매장 형태(테이크아웃형/체류형/배달형)를 입력함
3. 시스템은 해당 상권의 상주인구, 생활인구, 추정매출, 상권변화지표를 불러와 멀티에이전트 분석을 수행함
4. 최종적으로 시스템은 다음과 같은 설명형 진단 리포트를 제공함

> 이 상권은 점심 수요는 강하지만 저녁 체류가 약해 식사형 업종보다 테이크아웃형 업종에 유리합니다.  
> 현재 매출 규모는 양호하나 상권변화지표상 신규 진입 시 주의가 필요한 구간으로 해석되며, 초기 창업자가 참고해야 할 리스크 요인이 존재합니다.  
> 인근 대안 후보지 A는 유동인구는 낮지만 상주인구 기반이 더 안정적이므로 보다 보수적인 입지 검토 대상으로 판단됩니다.

## 7. 기대효과

이 시스템은 단순한 "핫플 추천" 서비스가 아니라, 공공데이터를 활용해 **예비창업자의 정보 비대칭을 줄이고 입지 판단 과정의 불확실성을 낮추는 창업 의사결정 지원 시스템**으로 기능할 수 있음.

특히 다음과 같은 장점을 가짐.

- 데이터 기반으로 상권을 설명하므로 설득력이 높음
- 사용자 맞춤형 진단 제공 가능
- 멀티에이전트 구조가 과장되지 않고 실제 역할 분담과 잘 맞음
- 공공데이터 활용성이 분명하여 공모전 소재로도 적합함

## 8. 한 줄 요약

> 서울시 상권·인구·매출 공공데이터를 통합 분석하여, 예비창업자가 특정 업종과 입지 조합의 진입 적합성, 주의 요인, 대안 입지 비교 정보를 사전에 확인할 수 있도록 지원하는 LLM 멀티에이전트 시스템 기반 창업 의사결정 지원 서비스
