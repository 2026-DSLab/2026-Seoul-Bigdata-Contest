# LLMAS 기반 전세사기 탐지 시스템

## 1. 시스템 개요
본 시스템은 LLM 기반의 다중 에이전트 시스템(Multi-Agent System, MAS)을 활용하여 전월세 사기(깡통전세, 불법 점유 등) 위협을 탐지하고 사용자에게 안전 지표를 제공하는 것을 목적으로 함. 서울시에서 제공하는 공공데이터를 바탕으로 각 에이전트가 서류 검토, 시세 연산, 이상 거래 탐지 등의 역할을 분담 수행하여 최종적인 주거 위험도를 평가함.

## 3. MAS 아키텍처

### 📄 Document Agent (검토 에이전트)
* **역할:** 사용자가 목표로 하는 가구의 건축물대장 기반 물리적/법률적 하자 텍스트 분석
* **입력 피처:** `주용도코드명`, `용도코드명(전유부)`, `가구수`, `사용승인일자`
* **처리 로직:**
  1. 목표 건축물의 주용도코드명 및 전유부 용도코드명을 확인하여 '근린생활시설'의 주거용 불법 전용 여부 판단.
  2. 표제부 가구수와 실제 임대 매물 수를 대조하여 불법 방 쪼개기 식별.
  3. 사용승인일자를 통해 건축물 노후도 검증.

### 💰 Price Risk Agent (시세 분석 에이전트)
* **역할:** 실거래가 기반 시장 가격 추론 및 주택담보대출비율(LTV) 연산
* **입력 피처:** `물건금액(만원)`, `건물면적(㎡)`, `보증금(만원)`, `종전 보증금`
* **처리 로직:**
  1. 최근 1년 유사 면적 매매가(`물건금액`) 평균 산출 및 전세 `보증금` 규모와 대조하여 깡통전세 위험 조기 노출.
  2. `종전 보증금` 대비 신규 보증금의 인상률을 분석하여 무자본 갭투자 의심 사례 필터링.

### 🕵️‍♂️ Fraud Detect Agent (이상 탐지 에이전트)
* **역할:** 메타데이터의 행동 패턴을 분석하여 비정상적 기만/투자 행위 탐지
* **입력 피처:** `취소일`, `신고한 개업공인중개사 시군구명`, `계약갱신권사용여부`
* **처리 로직:**
  1. 단기간 내 신고가의 빈번한 취소(`취소일`) 발생을 추적하여 시세 교란 행위 감지.
  2. 해당 지역 외부의 특정 중개사(`신고한 개업공인중개사 시군구명`)가 다수 개입한 기획 거래 패턴 식별.
  3. 건물 내 `계약갱신권사용여부` 비율이 낮을 경우 잦은 손바뀜에 따른 보증금 반환 사고 가능성 추론.

### 🧠 Master Agent (종합 결정 에이전트)
* **역할:** 서브 에이전트들의 독립적 결괏값을 병합하여 최종 안전 진단 리포트 도출
* **입력 피처:** Document Agent, Price Risk Agent, Fraud Detect Agent 의 분석 스코어
* **처리 로직:** 개별 탐지된 위험 경고를 취합하여 정량화. 최종 위험도를 3단계 구조(안전/주의/위험)로 산출하여 종합 평가 리포트 반환.

## 4. 사용자 경험(UX) 시나리오


1. **지도 기반 탐색 및 매물 핀(Pin) 선택:** 사용자가 플랫폼(앱/웹) 지도 UI 상에서 본인이 계약하고자 하는 건물(원룸/빌라 등)의 위치 마커를 터치.
2. **동·호수 입력 및 진단 요청:** 사용자가 관심 있는 정확한 호실(예: 302호)과 보증금 액수를 간단히 입력 후 '안전 진단' 버튼 클릭. (관공서 서류 캡처 및 업로드 과정 일체 생략)
3. **실시간 공공 API 호출 및 MAS 구동 (Backend):** 백엔드 서버가 해당 지번의 건축물대장(표제부/전유부), 실거래가, 전월세 공공데이터 API를 실시간 호출. 파싱된 JSON 피처들이 MAS 에이전트들에게 전달되어 교차 팩트체크 연산 시작.
4. **최종 안전 리포트 브리핑:** Master Agent가 직관적인 3단계 신호등(🟢안전 / 🟡주의 / 🔴위험)과 함께, "해당 302호는 서류상 사무소로 등록된 '근생빌라'이므로 전세대출이 불가능하며, 최근 이례적인 보증금 폭등이 발견되어 깡통전세 위험이 높습니다" 형태의 구어체 브리핑 보고서 반환.
