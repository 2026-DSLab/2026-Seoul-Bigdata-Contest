# 🏙️ 상권 분석 LLM 멀티에이전트 시스템 — 아키텍처 문서

> **프로젝트**: 2026 서울 빅데이터 공모전  
> **목적**: 점주(사용자)의 입력을 바탕으로 상권 데이터를 분석하고, LLM 멀티에이전트가 의사결정을 지원하는 시스템

## 3. 에이전트 상세 설명

### 3-1. DataLoader (Stage 1)

| 역할 | 설명 |
|------|------|
| **목적** | 사용자 입력 10개 필드 → enriched dict (50+ 필드) 생성 |
| **카카오 API** | `키워드 검색` 엔드포인트로 가게 좌표 조회 |
| **역세권 판단** | Haversine 공식, 가게↔역 거리 ≤ 300m → 역세권 |
| **CSV 조회** | 구·동 코드로 필터링, 카테고리별 집계 |
| **Fallback** | 카카오 API 실패 시 좌표 없이 CSV만으로 가능한 필드 채움 |

### 3-2. 상권활성도 에이전트 (Stage 2-①)

| 항목 | 내용 |
|------|------|
| **분석 대상** | 유동인구 시간대·성별·연령 분포 / 역세권 여부 / 매출 시간대 분포 |
| **핵심 질문** | "이 상권은 활발한가? 언제, 누가 많이 오는가?" |
| **출력** | Markdown 보고서 (상권활성도_보고서) |

### 3-3. 경쟁환경 에이전트 (Stage 2-②)

| 항목 | 내용 |
|------|------|
| **분석 대상** | 반경 유사업종 점포수 / 동 내 개·폐업률 / 프랜차이즈 비율 |
| **핵심 질문** | "경쟁이 치열한가? 시장이 성장 중인가, 포화 상태인가?" |
| **출력** | Markdown 보고서 (경쟁환경_보고서) |

### 3-4. 업종 추천 에이전트 (Stage 2-③)

| 항목 | 내용 |
|------|------|
| **분석 대상** | 동 내 카테고리별 월매출 순위 / 사용자 업종 매출 위치 |
| **핵심 질문** | "현재 업종이 이 상권에서 경쟁력 있는가? 더 유리한 업종은?" |
| **출력** | Markdown 보고서 (업종추천_보고서) |

### 3-5. 종합 분석 에이전트 (Stage 3-①)

| 항목 | 내용 |
|------|------|
| **입력** | Stage 2 보고서 3개 + 사용자 고민사항 |
| **역할** | 3개 보고서를 통합해 핵심 인사이트와 실행 가능한 솔루션 제시 |
| **출력** | 종합 분석 보고서 (우선순위별 액션 아이템 포함) |

### 3-6. 상권 작명 에이전트 (Stage 3-②)

| 항목 | 내용 |
|------|------|
| **입력** | Stage 2 보고서 3개 + 사용자 입력 (분위기, 시그니처 상품 등) |
| **역할** | 상권의 특성을 브랜드화하는 창의적인 이름 제안 |
| **출력** | 후보 이름 3개 + 각 작명 근거 |

## 4. LLM 제공자 분기

```
.env
└── LLM_PROVIDER=gemini  또는  openai
          │
          ▼
   base_agent.py
   ├── gemini  → google-generativeai SDK (gemini-2.0-flash)
   └── openai  → openai SDK (gpt-4o-mini)
          │
          ▼
   generate(system_prompt, user_message) → str
   (모든 에이전트가 동일 인터페이스 사용)
```

## 5. 데이터 흐름 (필드 매핑)

| 최종 JSON 필드 | 데이터 소스 | 방법 |
|---|---|---|
| `반경_유사업종_점포수` | 점포 CSV | 동 필터 + 카테고리 필터 |
| `가장_가까운_역` | 지하철역 CSV + 카카오 좌표 | Haversine 최솟값 |
| `역까지_거리_m` | 지하철역 CSV + 카카오 좌표 | Haversine |
| `카테고리_점포수` | 점포 CSV | 동 + 카테고리 집계 |
| `카테고리_개업률` / `폐업률` | 점포 CSV | 개업_점포수 / 전체 × 100 |
| `카테고리_프랜차이즈_점포수` | 점포 CSV | 프랜차이즈 필터 집계 |
| `동_전체_점포수` 등 | 점포 CSV | 동 전체 집계 |
| `최다/최저_매출_시간대` | 매출 CSV | 시간대별 금액 argmax/argmin |
| `매출_성별/연령대` | 매출 CSV | 성별·연령대별 금액 |
| `유동인구_*` | 유동인구 CSV | 시간대·성별·연령대 |
| `타겟_연령대_유동인구` | 유동인구 CSV | 사용자 연령층 매핑 |
| `타겟_성별_매출` | 매출 CSV | 사용자 성별 매핑 |

## 7. 환경변수 목록

| 변수명 | 설명 | 필수 여부 |
|--------|------|----------|
| `LLM_PROVIDER` | `gemini` 또는 `openai` | ✅ 필수 |
| `GEMINI_API_KEY` | Gemini API 키 | LLM_PROVIDER=gemini일 때 |
| `GEMINI_MODEL` | 사용할 Gemini 모델명 (기본: `gemini-2.0-flash`) | 선택 |
| `OPENAI_API_KEY` | OpenAI API 키 | LLM_PROVIDER=openai일 때 |
| `OPENAI_MODEL` | 사용할 OpenAI 모델명 (기본: `gpt-4o-mini`) | 선택 |
| `KAKAO_API_KEY` | 카카오 로컬 REST API 키 | 선택 (없으면 좌표 조회 생략) |
| `DATA_DIR` | 전처리 데이터 폴더 경로 | 선택 (기본: `../data/preprocessed`) |
