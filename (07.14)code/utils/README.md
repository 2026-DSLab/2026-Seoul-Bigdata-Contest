# code/utils/

### `input_builder.py`

위치, 교통, 상권데이터를 결합한 통합 분석 데이터 생성

- **입력(Input)**: 사용자 업종, 주소, 주요 고민 사항 등 (JSON)
- **출력(Output)**: 위치·교통·상권 통계가 통합된 종합 분석 데이터 (JSON)

### `data_loader.py`

행정 구역 및 업종 정보를 매핑하여 공공데이터셋으로부터 통계 지표 산출 및 반환

- **입력(Input)**: 행정동 코드, 서비스 업종명, 타겟 고객층 정보(성별/연령)
- **출력(Output)**: 점포 현황(개·폐업률), 유동인구 통계, 매출 분석 지표

### `kakao_api.py`

외부 Local API를 통한 사업장의 지리적 좌표 및 주변 환경 데이터 추출

- **입력(Input)**: 사업장 상호명 및 주소 문자열
- **출력(Output)**: 위경도 좌표(Lat/Lng) 및 특정 반경 내 유사업종 점포 수

### `subway_station.py`

사업장 좌표와 인접 대중교통 인프라 간의 거리 측정

- **입력(Input)**: 사업장 위도/경도 좌표
- **출력(Output)**: 최단 거리 지하철역 명칭 및 물리적 이격 거리(m)

### `load_input.py`

외부 입력 파일의 무결성 검증 및 데이터 직렬화

- **입력(Input)**: 사용자 입력 파일 경로(Path)
- **출력(Output)**: 정규화된 Python 딕셔너리(Dictionary) 객체
