# LLM 멀티에이전트 기반 팝업스토어 입지·운영 검증 시스템

## 1. 시스템 개요
브랜드가 팝업스토어를 기획할 때 실제로 부딪히는 핵심 문제는 다음 3가지가 동시에 충족되지 않는다는 점이다.

- **유입량이 높은 곳**
- **브랜드 타깃과 실제로 잘 맞는 곳**
- **경쟁 및 운영 리스크가 감당 가능한 곳**

본 시스템은 이러한 상충 관계를 **LLM 기반 다중 에이전트 시스템(MAS)** 으로 중재하여, 단순히 “사람 많은 곳”을 추천하는 것이 아니라 **브랜드 목적에 맞는 전략 상권과 운영 시기·시간대** 를 도출하는 팝업스토어 입지·운영 검증 솔루션이다.

특히 1차 버전은 **서울시 공공데이터만을 활용**하여 설계하며, 민간 카드매출·실시간 SNS 버즈·실제 대관 가능 공간 정보 없이도 **입지성, 유입 특성, 업종 적합성, 경쟁 리스크** 를 구조적으로 검토할 수 있도록 구성한다.

## 3. MAS 아키텍처

### 🚶 Flow Agent (유입·접근성 검토 에이전트)
- **역할:** 사람이 실제로 많이 들어오는 상권인지, 그리고 내가 열고 싶은 시간대에 그 유입이 발생하는지 검증
- **입력 피처:**
  - `상권영역`
  - `일평균 유동인구`
  - `유동인구 밀도`
  - `요일별 유동인구`
  - `시간대별 유동인구`
  - `지하철 시간대 승하차`
  - `버스 정류장 시간대 승하차`
- **처리 로직:**
  1. 후보 상권별 유입량 스코어 산출
  2. 희망 운영 시간대와 실제 유입 시간대 일치 여부 검증
  3. 지하철·버스 기반 접근성이 약한 상권 감점
  4. 필요 시 S-DoT 데이터로 최종 후보군 현장 유동 재검증

### 🎯 Demand-Fit Agent (타깃·매출 정합성 검토 에이전트)
- **역할:** 단순히 사람이 많은 곳이 아니라, 브랜드 고객이 실제로 올 가능성이 높은 곳인지 판별
- **입력 피처:**
  - `직장인구`
  - `상주인구`
  - `성별/연령별 비중`
  - `소득수준`
  - `소비트렌드`
  - `유사 업종 매출 패턴`
- **처리 로직:**
  1. 브랜드 타깃과 상권 인구 구조 매칭
  2. 유사 업종의 시간대별·연령대별 매출 패턴 기반 전환 가능성 추정
  3. 유입은 높지만 타깃과 맞지 않는 상권은 후순위 조정

### ⚠️ Risk Agent (경쟁·운영 리스크 검토 에이전트)
- **역할:** 과열 상권, 포화 상권, 경쟁 강도가 높은 상권을 걸러냄
- **입력 피처:**
  - `점포수`
  - `개업/폐업`
  - `프랜차이즈 여부`
  - `상권변화지표`
  - `집객시설`
  - `문화행사`
- **처리 로직:**
  1. 동일/유사 업종 과밀 여부와 프랜차이즈 비중 계산
  2. 상권변화지표를 통해 성장/정체/축소 리스크 반영
  3. 주변 행사·유통점·공연장 등 집객 요소는 가점, 포화도는 감점

### 🧠 Master Agent (종합 타협·운영 전략 에이전트)
- **역할:** 세 에이전트 결과가 충돌할 경우, 브랜드 목적에 맞는 전략을 설계
- **처리 로직:**
  1. 교집합이 없으면 브랜드 목표에 따라 가중치 재조정
     - **브랜딩형:** 유입량 가중치 ↑
     - **판매형:** 전환 가능성 가중치 ↑
     - **체험형/팬덤형:** 타깃 정합성·행사 시너지 가중치 ↑
  2. 임계값을 10~15% 범위에서 완화하여 대안 상권 재탐색
  3. 최종적으로 아래 전략 중 하나를 선택해 리포트 생성
     - **유입량 우선형**
     - **타깃 적합 우선형**
     - **리스크 회피형**
     - **이벤트 연동형**

## 4. 사용자 경험(UX) 시나리오

### 4.1. 브랜드 조건 입력
사용자가 다음과 같은 핵심 정보를 입력한다.

- **브랜드 카테고리:** F&B / 패션 / 뷰티 / 굿즈 / 체험형 등
- **목표:** 브랜드 노출 / 판매 전환 / 신규 고객 확보 / 팬덤 활성화
- **핵심 타깃:** 연령, 성별, 직장인 여부, 생활권 소비자 여부
- **운영 조건:** 희망 요일, 시간대, 운영 기간
- **우선순위:** 유입량 / 타깃 정합성 / 경쟁 안전성 중 절대 포기 못 할 요소 선택

### 4.2. MAS 교차 연산 및 딜레마 중재
- **Flow Agent** 가 시간대별 유입과 대중교통 접근성을 기준으로 상권 후보군 추출
- **Demand-Fit Agent** 가 직장인구·상주인구·소득소비·유사 업종 매출 데이터를 바탕으로 타깃 적합성 검증
- **Risk Agent** 가 경쟁 과밀, 프랜차이즈 비중, 개폐업 흐름, 상권변화지표를 반영하여 리스크 보정
- **Master Agent** 가 교집합이 없을 경우 목표 기반 타협 전략 설계

### 4.3. 전략 상권 및 운영전략 리포트 출력
- 지도 위에 추천 상권 2~3개를 마커로 표시
- 상권별 추천 근거를 문장형 리포트로 설명

**[분석 리포트 예시]**  
> “현재 목표가 ‘판매 전환’이라면, 단순 유입량만 높은 **상권 A** 보다 20~30대 타깃 비중과 유사 업종 매출 패턴이 더 잘 맞는 **상권 B** 가 유리합니다.  
> **상권 A** 는 주말 유동은 강하지만 동일 업종 경쟁도가 높고 상권 포화가 강합니다.  
> **차라리 총유입은 조금 낮더라도 상권 B로 가서 ‘타깃 적합 우선 전략’을 쓰는 편이 실제 전환 가능성이 높습니다.**”

**[운영 팁 예시]**  
> “주변 문화행사 일정상 토요일 14~18시에 추가 유입이 예상되므로, 체험형 이벤트 또는 한정 굿즈 공개 시간을 해당 구간에 맞추는 것이 유리합니다.”

### 4.4. 실장소 탐색 연동
최종 산출물은 단순 상권 추천이 아니라 다음을 함께 제시한다.

- **어느 상권에서**
- **어떤 시간대에**
- **어떤 전략으로**
- **왜 그 상권이 적합한지**

이후 실제 대관 가능 공간 탐색은 네이버 지도, 공간대여 플랫폼, 복합쇼핑몰 대관 페이지 등으로 후속 연동 가능하다.

## 5. 서울시 공공데이터 한정 1차 버전의 장점과 한계

### 장점
- 서울시 공공데이터만으로도 **상권 후보 선정**
- **시간대 추천**
- **타깃 적합성 검증**
- **경쟁 및 운영 리스크 점검**
까지 구조적으로 수행 가능

### 한계
다만 1차 버전에서는 아래 요소를 직접 다루기 어렵다.

- 실제 대관 가능 공간 정보
- 실시간 SNS 버즈 및 검색량
- 민간 카드매출 데이터
- 정확한 임대조건
- 행사장 내부 유동 및 체류시간 데이터

따라서 본 시스템은 **서울시 공공데이터 기반 1차 검증 플랫폼** 으로서 의미가 있으며, 추후 민간 데이터/API를 연결하면 **실행형 의사결정 시스템** 으로 확장 가능하다.
