
# LLMAS 기반 주거지 타협 스캐너

## 1. 시스템 개요
직장인이 거주지를 선택할 때 반드시 직면하는 3원 상충 (통근 거리, 주거 예산, 생활 인프라)의 구조적 한계를 LLM 기반 다중 에이전트 시스템(MAS)으로 중재하여, 단순 매물 검색이 아닌 **나에게 가장 최적화된 '전략적 거점(행정동)'과 '타협 전략'** 을 도출하는 입지 선정 분석 솔루션. 사용자가 직접 발품을 팔기 전, 공공데이터를 기반으로 확률적으로 가장 유리한 지역을 선점할 수 있도록 돕는 '주거 전략 스캐너' 역할을 수행.

## 2. 활용 데이터셋 및 피처 명세

### 2.1. 서울시 부동산 전월세가 정보 
* **API 링크:** [서울시 부동산 전월세가 정보 (OA-21276)](https://data.seoul.go.kr/dataList/OA-21276/S/1/datasetView.do)
* **데이터 목적:** 사용자 예산 한계선과 행정동별 평균 시세의 교차 검증 및 진입 타당성 평가
* **전체 피처(Feature):**
  > `접수연도`, `자치구코드`, `자치구명`, `법정동코드`, `법정동명`, `지번구분`, `지번구분명`, `본번`, `부번`, `층`, `계약일`, `전월세 구분`, `임대면적(㎡)`, `보증금(만원)`, `임대료(만원)`, `건물명`, `건축년도`, `건물용도`, `계약기간`, `신규갱신여부`, `계약갱신권사용여부`, `종전 보증금`, `종전 임대료`
* **🔥 핵심 활용 피처:**
  - **시세/예산 연산:** `보증금(만원)`, `임대료(만원)`, `전월세 구분`
  - **주거 질 검증:** `임대면적(㎡)`, `건축년도`, `층`
  - **거점 식별:** `자치구명`, `법정동명`

### 2.2. 출퇴근 소요시간, 환승 횟수, 도보 이동 거리, 피로도 연산
단순 물리적 거리가 아닌 실제 출근 환경의 피로도를 계산하기 위해 외부 API를 활용

**A. 자차(Driving) 소요시간 : Tmap [타임머신 자동차 길 안내 API](https://tmap-skopenapi.readme.io/reference/%ED%83%80%EC%9E%84%EB%A8%B8%EC%8B%A0-%EC%9E%90%EB%8F%99%EC%B0%A8-%EA%B8%B8-%EC%95%88%EB%82%B4)**
* **🔥 핵심 파라미터:**
  - `departureTime`: 사용자의 실제 출근 시점을 입력하여 과거 교통 변화 추이를 반영한 특정시각의 소요 시간 추출가능
  - `startX`, `startY` / `endX`, `endY`: 거점 간 정교한 좌표 기반 경로 연산.

**B. 대중교통(Transit) 소요시간 : Tmap [대중교통 API](https://openapi.sk.com/products/detail?svcSeq=59&menuSeq=492)**
* **🔥 핵심 파라미터:** 
  - `departureTime`: 자차 API와 마찬가지로 출근 시점의 대중교통 경로 및 소요 시간(역사 내 도보 시간 포함) 연산 가능.
  - `totalTime`, `totalWalkTime`, `transitCount`: 총 이동 시간, 도보 거리, 환승 횟수 등 피로도 지표 추출.

**C. 공공데이터포털 [서울교통공사_지하철 혼잡도 정보](https://www.data.go.kr/data/15071311/fileData.do)**
* **데이터 목적:** 단순 소요 시간을 넘어, 출근길의 '쾌적도(육체적 피로도)'를 정량적으로 평가하기 위함.
* **🔥 핵심 피처:** 
  - `요일구분`, `역명`, `호선`, `30분단위_혼잡도(%)`

### 2.3. 집근처 인프라 데이터 
사용자 실거주지 주변의 실제 생활 편의 수준을 평가하기 위해 상업지구 분석 대신 실시간 장소 검색 API를 활용함.

**카카오 [키워드로 장소 검색 API](https://developers.kakao.com/docs/latest/ko/local/dev-guide#search-by-keyword)**
* **🔥 핵심 파라미터:** 
  - `query`: 대상 업종(편의점, 빨래방, 병원, 대형마트 등) 키워드 검색.
  - `category_group_code`: 특정 업종(CS2:편의점, HP8:병원, PM9:약국 등) 그룹 기반 정밀 필터링 가능.
  - `x`, `y`, `radius`: 주거 거점 좌표 기준 특정 반경(예: 500m) 내의 인프라 밀집도 추출.
* **에이전트 연산:** Infra Agent가 해당 반경 내 필수 인프라의 개수 및 거리를 정량화하여 '거주 적합성 점수' 산출.

### 2.4. 역세권 청년주택 공공임대 공실률 현황 (선택적 대안 검토용)
* **출처:** [서울열린데이터광장 (OA-21308)](https://data.seoul.go.kr/dataList/OA-21308/S/1/datasetView.do)
* **데이터 목적:** 일반 매물로 조건 충족이 어려울 경우, 인근의 공공주택(청년주택)이라는 추가 선택지를 정보 차원에서 제공.
* **피처(Feature):** `사업대상지`, `공공임대 공급호수`, `공실`, `공실률`
* **🔥 활용 지표:** 
  - `공실률`: 해당 지역 공공주택의 공급 여력을 파악하여 '우회 가능한 옵션'이 있는지 판단하는 참고 지표.

## 3. MAS 아키텍처

### 🚇 Distance Agent (통근 검토 에이전트)
* **역할:** 직장 위치를 기준으로 사용자의 통근 시간 허용치를 방어
* **입력 피처:** `출발지_법정동`, `도착지_법정동`, `최단_이동시간(분)`, `평균_환승횟수`
* **처리 로직:**
  1. 도착지(직장) 기준 유저가 설정한 최대 소요 시간(예: 40분) 이내에 도달 가능한 법정동 리스트 1차 추출.
  2. 환승 횟수가 2회 이상인 피로도 누적 구간 배제.

### 💰 Budget Agent (재무 검토 에이전트)
* **역할:** 유저의 가용 자본 내에서 최소한의 주거 면적(평형) 확보
* **입력 피처:** `보증금(만원)`, `임대료(만원)`, `임대면적(㎡)`, `법정동명`
* **처리 로직:**
  1. Distance Agent가 넘겨준 법정동 리스트 중, 유저 예산(예: 전세 1.5억)으로 진입 시 평균 `임대면적`이 20㎡(약 6평) 미만으로 떨어지는 구역 필터링.
  2. 예산 대비 넓은 면적 확보가 가능한 외곽 법정동에 가점 부여.

### 🏪 Infra Agent (환경 검토 에이전트)
* **역할:** 거점의 생활 편의성 방어
* **처리 로직:**
  1. 카카오 API를 통해 산출된 반경 내 필수 인프라(편의점, 대형마트, 약국 등)의 개수를 합산.
  2. 도보 5분(약 300~400m) 내 핵심 POI가 존재하지 않는 구역에 감점 부여하여 선호도 재조정.

### 🧠 Master Agent (종합 타협 에이전트)
* **역할:** 3개 에이전트의 교집합이 소실되는 교착 상태(Deadlock) 발생 시, 제약 조건을 완화(Relaxation)하여 대안 거점을 도출하고, 공공주택 정보를 **'추가 옵션'**으로 탐색.
* **처리 로직:**
  1. 교집합이 없을 경우, 유저의 우선순위 가중치를 바탕으로 거리/예산/인프라 변수를 15% 내외에서 완화하여 대안 거점 재탐색.
  2. 도출된 거점 인근에 **역세권 청년주택 공실(OA-21308)**이 존재하는지 매칭 확인.
  3. 공실 데이터가 존재할 경우, 브리핑 리포트에 **[마이홈 포털]** 링크와 함께 "함께 고려해볼 수 있는 대안 주거 정보"를 팁(Tip) 형태로 제안.

## 4. 사용자 경험(UX) 시나리오

1. **조건 및 가중치 입력:** 사용자가 다음과 같은 핵심 정보를 입력.
   - **주거 형태:** 전세 / 월세 선택
   - **직장 정보:** 회사 위치(주소) 및 이동수단(대중교통/자차 여부)
   - **재무 조건:** 가용 예산(보증금, 월세 상한선)
   - **우선순위:** 거리, 예산, 인프라 중 '절대 포기 못 할 요소'와 '우선 포기 가능한 요소' 설정.
2. **MAS 교차 연산 및 딜레마 중재 (Backend):** 
   - Distance Agent가 이동 수단(Tmap)을 고려하여 후보군 추출.
   - Budget Agent가 실거래 데이터(2.1)를 분석하여 해당 예산으로 진입 가능한 행정동 필터링.
   - Master Agent가 교집합이 없을 경우 사용자의 우선순위에 따라 '최적의 포기 전략' 수립.
3. **타협 거점 및 전략 리포트 출력:** 지도 상에 추천된 2~3개의 행정동 마커를 노출하고, 상세 분석 리포트 제공.
   - **[분석 리포트 예시]:** "현재 예산(전세 1.5억)으로 강남 출퇴근 30분을 유지하려면 인프라를 포기하고 [거점 A]로 가야 하지만, 카카오 데이터 분석 결과 해당 구역은 편의시설이 부족합니다. **차라리 통근을 15분 늘려 [거점 B]로 가시는 '거리 타협 전략'을 쓰면 예산 내에서 7평 이상의 넓은 방과 풍부한 인프라를 동시에 챙길 수 있습니다.**"
   - **[보너스 옵션]:** "참고로 해당 거점 인근 '역세권 청년주택' 공실 정보가 포착되었으니 체크해 보시는 것도 대안이 될 수 있습니다."
4. **실매물 탐색 연동 (External):** 도출된 최적의 타협 거점(행정동) 정보를 검색 필터로 담아, **네이버 부동산/직방** 등의 외부 플랫폼 실매물 검색 페이지로 Redirection.
